## 2. Zone Allocations

| Zone | Zone Name                          | Key Features                                              |
|------|------------------------------------|-----------------------------------------------------------|
| Z1   | Raw Material Store                 | Temperature-controlled; FIFO; hazmat sub-zone where req'd |
| Z2   | Primary Production Zone            | GMP-grade; positive pressure; washable walls/floors       |
| Z3   | Filling + Primary Packaging        | CIP-accessible; cleanroom air supply                      |
| Z4   | Secondary Packaging                | Carton erector; shrink tunnel; palletiser                 |
| Z5   | Finished Goods Warehouse           | Temperature-controlled zones; pallet racking              |
| Z6   | Cold Chain / Refrigerated Storage  | Where applicable; 2–8°C or 0°C to −18°C                  |
| Z7   | Utilities (Boiler, CIP, Air)       | Boiler house; CIP skid; compressed air room              |
| Z8   | QC Laboratory                      | Microbiology; physical/chemical testing; stability room   |
| Z9   | In-Process QC + Final Inspection   | Checkweigher; vision; metal detector; OBA sampling        |
| Z10  | Maintenance Workshop               | Tool room; spare parts; electrical workshop               |
| Z11  | IT / MES Server Room               | Edge servers; SCADA; network core                        |
| Z12  | Staff Facilities                   | Canteen; locker rooms; change rooms (GMP entry procedure) |

## 4. GMP Production Zone Requirements

| Feature                  | Requirement                                                     |
|--------------------------|-----------------------------------------------------------------|
| Flooring                 | Epoxy resin (food-grade, coved skirting)                        |
| Walls                    | Hygienic cladding panels (GRP or stainless steel bonded)       |
| HVAC                     | Positive pressure; HEPA filtered; 10–12 air changes/hour        |
| Personnel Flow           | Segregated GMP entry (change rooms → airlocks → production)     |
| Waste Handling           | Separate waste exit; washable waste collection stations         |
| Pest Control             | Electronic fly killers; door seals; site pest control contract  |
